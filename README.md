# 🩺 Healthcare-Agent

An AI agent that reads lab reports and healthcare PDFs and gives clear, general, non-diagnostic lifestyle guidance. Upload a report, see which results are flagged, personalize the answer, and ask follow-up questions by typing or by voice.

> ⚕️ **Disclaimer:** This project provides general information only. It is not medical advice, diagnosis, or treatment. Always consult a doctor.

## ✨ Features

- 📄 **PDF analysis:** upload any lab report or healthcare PDF, and switch to a new one at any time
- 🔬 **Flagged results table:** High, Low, and Abnormal tests with values and reference ranges
- 💡 **Guidance by test:** plain-language explanations with general food and lifestyle tips
- 🎛️ **Personalization panel:** one Settings button opens preferences for:
  - language (English, Hindi, Telugu, Tamil, Spanish, French, German)
  - tone, detail level, answer length, response format, and reading level
  - diet, preferred cuisine, budget-friendly foods, and foods to avoid
  - focus area, health goal, activity level, and age group
- 🔒 **Privacy mode:** hides names, IDs, emails, and phone numbers from the uploaded PDF before the agent reads it (best-effort)
- 🎙️ **Voice input:** record a question with the microphone and it is transcribed with Whisper
- 🔊 **Read aloud:** hear the latest reply in the selected language
